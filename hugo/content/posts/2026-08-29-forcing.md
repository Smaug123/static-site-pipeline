So, [set-theoretic forcing](https://en.wikipedia.org/wiki/Forcing_(mathematics)).

Prerequisites:

* \\(V\\) is the [von Neumann universe](https://en.wikipedia.org/wiki/Universe_(mathematics)).
* We'll define the real numbers as subsets of the naturals. (We can do this: \\(2^\mathbb{N} \le \mathbb{N}^\mathbb{N} \le (2^\mathbb{N})^\mathbb{N} \le 2^{\mathbb{N} \times \mathbb{N}} \le 2^\mathbb{N}\\), so there are bijections throughout, so whatever kind of reals you thought you were working with, like \\(2^\mathbb{N}\\), you can swap to the others.)
* There is a countable transitive model of [ZFC](https://en.wikipedia.org/wiki/Zermelo%E2%80%93Fraenkel_set_theory) (note that the existence of a not-necessarily-transitive model is the downward [Löwenheim-Skolem theorem](https://en.wikipedia.org/wiki/L%C3%B6wenheim%E2%80%93Skolem_theorem); making it transitive is strictly stronger, but it's much easier to work with; you can do without that, but you'll have to see [Kunen](https://en.wikipedia.org/wiki/Set_Theory:_An_Introduction_to_Independence_Proofs) for that).
* This model manages to contain a set of reals, which it thinks are *all* the reals.
* [Skolem's paradox](https://en.wikipedia.org/wiki/Skolem's_paradox): \\(M\\) contains a set \\(\mathbb{R}_M\\) which it thinks is \\(\mathbb{R}\\), although it's wrong about that, not least because every set in \\(M\\) is countable. It doesn't realise its proposed \\(\mathbb{R}_M\\) is countable: a countable set is one which admits a bijection \\(f\\) between itself and \\(\mathbb{N}\\), but \\(M\\) is really small, and one of the hugely many sets that didn't make it into \\(M\\) was \\(f\\).

The various aims will be to show that:

* it's consistent with ZF for there to be a [Dedekind-finite set](https://en.wikipedia.org/wiki/Dedekind-infinite_set) which is not finite. (That is, an infinite set which doesn't biject with a proper subset of itself.)
* the negation of [CH](https://en.wikipedia.org/wiki/Continuum_hypothesis): it's consistent for \\(2^{\aleph_0} > \aleph_1\\).

*Forcing* is a tool to add stuff to a model (which is easy) in a useful way (which is extremely nontrivial).
For example, in order to disprove CH, we just need to make sure our model contains lots and lots of reals (more than \\(\aleph_1\\)-many) without accidentally also adding bijections between existing cardinals (which could even make the continuum *smaller*!).

# Toy setting we'll use

Let's try and add a single real number \\(r\\) to \\(M\\).
(There certainly *is* such a real number, because \\(M\\) is countable but there are uncountably many reals.)

# Constraint on the tools we're looking for

* We want to expand \\(M\\) by adding a real number \\(r\\); call the expansion \\(M[r]\\), and it contains \\(r\\) and still has \\(M\\) as a subset.
* \\(M[r]\\) must continue to be a transitive model of ZFC.
* \\(M[r]\\) must have the same ordinals as \\(M\\).

Adding additional ordinals is something we really don't want to do, because they would genuinely expand \\(M\\).
If we got really unlucky, maybe we would add so many ordinals that our expanded \\(M[r]\\) would become large enough to notice that the original subset \\(M\\) was itself a model of ZFC, which is a massive increase in the theory it's modelling (\\(M[r]\\) being a model of "ZFC + Con(ZFC)" makes it not a very representative model of ZFC alone!).
The questions we were trying to solve could have different answers in this stronger setting.

In fact, what if we accidentally added unrelated theorems directly that we didn't want?
(E.g. in the course of adding some \\(r\\), we also threw in the truth of the continuum hypothesis, when we weren't required to at all?)
We will definitely need some more minimality; let's go with "the most minimal possible":

* Every element of \\(M[r]\\) is first-order definable in \\(M[r]\\) from \\(r\\) and parameters in \\(M\\).

All of those elements are certainly going to be *necessary*; in fact it will turn out that such a small extension *is* possible while not breaking the other properties, for many \\(r\\) sufficiently "generic", although it's extremely nonobvious and it got Cohen a Fields medal.

# Dumbest naive approach: just add it, along with everything else we're forced to

This section describes why the dumbest possible approach doesn't work, and why we need a more powerful tool such as forcing.

We'll show that there are reals which you can't add to \\(M\\) without also being forced to add additional ordinals to \\(M\\).
More handwavily, we'll show that there are real numbers which encode enough information about \\(M\\) that \\(M\\) itself cannot contain them.
(This is, I think, completely unrelated to Gödel-style proofs, which otherwise have statements which vibe similarly.)

Let \\(\alpha\\) be the ordinal height of \\(M\\) - that is, it is the intersection \\(M \cap \mathrm{Ord}\\); by transitivity of \\(M\\), this intersection is an ordinal.
Since \\(M\\) is countable, so is that intersection; count it, say as \\((a_0, a_1, \dots)\\) (that is, the \\(a_i\\) are precisely the enumerated members of \\(\alpha\\), and hence are ordinals).
(By the way, it's not finite. Good luck getting a model of the axiom of infinity with only finitely many ordinals.)

This counting defines a well-ordering \\(\triangle\\) on \\(\mathbb{N}\\), namely: \\(i \triangle j\\) as naturals iff \\(a_i < a_j\\) as ordinals.
A well-ordering is a particular kind of binary relation, and a binary relation is a subset of \\(\mathbb{N} \times \mathbb{N}\\), which we can view (by [Cantor pairing](https://en.wikipedia.org/wiki/Pairing_function)) as a subset of \\(\mathbb{N}\\) - that is, as a real number; call it \\(r_\alpha\\).

Now, suppose \\(M\\) were extended to contain \\(r_\alpha\\).
All the reasoning which we did above can be performed inside \\(M[r]\\) and backwards. For example:

* Natural numbers are just finite ordinals, and all of those are implemented by the same objects in \\(M[r]\\) as \\(V\\) (in fact, in all transitive models of ZFC).
* The pair-set axiom (plus Extensionality) define the implementation of a pair set, so again, finite tuples are implemented by the same objects in \\(M\\) as \\(V\\).
* The Cantor pairing function (and natural addition and multiplication and division) are just statements of arithmetic about functions built by the recursion theorem. It's not obvious, but these *are* [absolute](https://en.wikipedia.org/wiki/Absoluteness_(logic)) for all transitive models of ZFC; this results from [Shoenfield's absoluteness theorem](https://en.wikipedia.org/wiki/Absoluteness_(logic)#Shoenfield's_absoluteness_theorem), although I think that's a sledgehammer and you can prove primitive-recursive functions to be absolute for transitive models directly.
* The well-ordering we construct from \\(r_\alpha\\) is of course a total order according to \\(M[r]\\), but \\(M[r]\\) also believes us in our assertion that it's a well-ordering: a well-ordering is a total order where every nonempty set has a least element, and there are even fewer nonempty sets in \\(M[r]\\) than there were in \\(V\\), so it's actually easier for a set to be a well-ordering in \\(M[r]\\) than it was in \\(V\\).
* That well-ordering has an order type: it's a theorem of ZFC that a well-ordered set is order-isomorphic to a unique ordinal.

That is, in adding \\(r_\alpha\\) in \\(M\\), we were forced also to add \\(\alpha\\), which means we've strictly increased the number of ordinals in \\(M\\).
That's one of the few things we absolutely had to not do!

So we need to find a recipe that *doesn't* risk adding any "dangerous" reals.

# "Minimality"
